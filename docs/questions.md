# First Questions

These are the highest-leverage questions to answer before writing the API integration.

1. What exact Maintenance Connection API are we integrating with?
2. Do you already have API credentials and docs?
3. Is there a non-production environment we should target first?
4. Which 3 to 5 business entities matter most?
5. What MCP client will use this server first?
6. Are there data classes we must not expose?
7. Do you want natural-language querying only, structured filters only, or both?
